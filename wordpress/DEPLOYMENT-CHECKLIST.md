# APEXIK 上线检查清单

## 基础环境

- [ ] 生产环境为当前稳定版 WordPress、PHP 8.3+、MySQL 8 / MariaDB 10.11+。
- [ ] DNS 已解析，HTTPS 强制开启，`www` 与根域名只保留一个主版本。
- [ ] 固定链接设为 `Post name`，时区、管理员邮箱和站点语言正确。
- [ ] 安装 WooCommerce、APEXIK 主题与 APEXIK Starter Content 插件。
- [ ] 在「工具 → APEXIK Setup」运行一次导入，并确认主题/Starter Content 版本为 1.7.0。

## 商务配置

- [ ] 商店地址、美元/欧元策略、含税/未税显示和销售地区已确认。
- [ ] Stripe/PayPal 先在测试模式完成支付、失败支付、退款与邮件流程，再切换正式账户；Stripe 的 Payment、Payout、Webhook、Sync 状态均为可用。
- [ ] 美国、英国、欧盟和其他目标国家的运费、时效、免邮和禁运规则已配置。
- [ ] 税务/VAT/IOSS 方案由财税专业人员确认。
- [ ] 库存、SKU、变体、包装重量与尺寸已经校对。

## 内容与合规

- [ ] 删除所有示例评论、示例评分和占位联系信息。
- [ ] 隐私政策、Cookie 政策、销售条款、退货政策、运输政策和联系信息可访问。
- [ ] Cookie 同意会在授权前阻止非必要分析/广告脚本。
- [ ] 邮件服务商确定后填写 Newsletter form action URL；在此之前站点不收集访客邮箱。
- [ ] 产品名、描述、图片、包装与广告素材已完成商标、版权、外观设计与不正当竞争风险复核。
- [ ] 未获授权时，不使用 F1 或任何车队/车手/赛道/赞助商的受保护标识。

## 技术与运营

- [ ] SMTP/交易邮件服务已配置，下单、发货、退款与密码重置邮件正常。
- [ ] 自动备份、异地存储、恢复演练、安全扫描和管理员 2FA 已开启。
- [ ] CDN/缓存不缓存 Cart、Checkout、My Account，图片已生成 WebP/AVIF。
- [ ] GA4/Search Console 或选定的分析方案已配置，电商事件可校验。
- [ ] 390 px、768 px、1440 px 尺寸通过视觉回归测试。
- [ ] 真实手机完成加购、优惠码、结账、付款、邮件和退款测试。
